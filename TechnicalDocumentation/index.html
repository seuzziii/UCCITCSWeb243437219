Introduction

Networking requires basic skills to set up new network or maintain and upgrade an existing one.You’ll have configure switches and end devices so that they are secure and perform effectively based on your requirements.

Modes

EXEC Mode - Limited capabilities, mainly for basic monitoring commands.

Privileged EXEC Mode - Full access to all commands and features.

Global Configuration Mode - Used for making configuration changes to the device.

Interface Configuration Mode - Used to configure specific interfaces on the device.

Line Configuration Mode - Used to configure terminal lines for remote access.

  • To enter Privileged EXEC Mode from User EXEC Mode, use the command: enable
  • To enter Global Configuration Mode from Privileged EXEC Mode, use the command:configure terminal
  • To exit from any configuration mode back to Privileged EXEC Mode, use the command:end
  • To go back to the previous configuration mode:exit
Names

The first configuration command on any device should be to give it a unique device name or hostname, if all switches in a network were left with their default names, it would be difficult to identify a specific device.

  • Use a name that reflects the device's role or location.
  • Avoid using special characters or spaces; use hyphens or underscores instead.
  • Keep the name concise but informative.
Passwords

Passwords are essential for securing access to network devices. They help prevent unauthorized access and protect sensitive configuration data, usage of weak or easily guessed passwords continues to be the biggest security concern of organizations.

  • Use a combination of uppercase and lowercase letters, numbers, and special characters.
  • Avoid using common words or easily guessable information.
  • Change passwords regularly and avoid reusing old passwords.
  • Implement multi-factor authentication where possible for added security.
Configuration

To set the device name, enter Global Configuration Mode and use the following command:

hostname <device-name>

To set passwords for different access levels, use the following commands in Global Configuration Mode:

  1. Set the console password:
    2. line console 0
    password <password>
    login
  2. Set the VTY (Telnet/SSH) password:
    3. line vty 0 4
  3. Set the enable password:
    4. enable secret <password>
  4. Encrypt the password
    5. service password-encryption
  5. Set banner message for warning
    6. banner motd # <message> #
